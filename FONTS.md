# Bundled fonts

Fonts in `app/src/main/res/font/`, used for the home-screen clock (`ClockFonts.kt`).

| File | Font | License | Source |
|---|---|---|---|
| `jetbrains_mono.ttf` | JetBrains Mono (variable, weight 100–800) | SIL Open Font License 1.1 | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |

The clock uses weight 700 (`Style.clockFont` in `LauncherScreen.kt`).
